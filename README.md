# 80億分の1 — 出生条件カスタム・チート版（非公式）

公開サイト「80億分の1」の保存ファイルに基づく非公式改造版です。出生条件の手動設定、プレイ途中のパラメータ変更、特殊な出生プリセットを試験的に追加しています。

原作: https://1in8b.life/ja/

## 機能
- 出生国・性別・家庭階層・王族／旧貴族・都市／農村・初期健康／幸福／才能を指定
- 王族・皇族・アメリカ大統領の子などの出生プリセット
- 1950年代パプアニューギニア・北センチネル島を想定した仮想プリセット
- プレイ中の各種パラメータ変更
